Connect to the local controller.

01 / SET THE POSITIONS

Pair / Position

Start pairing, then tap the red phones from top left to bottom right. Green means assigned.

02 / TRY THE WALL

Send Test Text

Red serif text, fitted inside the full screen height. Each row scrolls from right to left, staggered.

Up to 120 characters. Emoji appearance depends on the phone's iOS version.

Slower ← → Faster. Choose a speed, then send a new test. Try 80–120 for slower motion.

Pair your phones first, then send a test. No phone-app update needed.

03 / INCOMING MESSAGES

Live SMS

The Tenda router is watched automatically. Each new incoming SMS interrupts the first row not already showing an SMS, including during Barthes or Kissing Wall. Messages already on the SIM at first connection are skipped.

04 / TEXT ARCHIVE

Roland Barthes Mode

Sentences from the local archive scroll across available rows in green, in book order, at a different fast speed for each sentence. The sequence loops automatically.

05 / VIDEO

Kissing Wall

Each phone plays random kissing clips independently, with sound. The Mac downloads clips once and shares them locally. Cached clips keep playing during outages.

Requires phone app 2.4 once. Settings apply to the next clip without reinstalling. Set each phone's speaker volume using its volume buttons.

TWO-ROW MESSAGES

Curated Mode

Each of the first two rows repeats its own message. An included library message appears about every 20–35 seconds. Incoming SMS still take priority.

Messages

Click a message to include it in the rotation. Click again to remove it.

06 / DIAGNOSTICS

Phone Debug Display

Show the app version, connection state and last error code on each phone.

Staged Artwork Releases

Edit the declarative draft, preview it locally, then prepare the same immutable release on one phone, a group, and the entire wall. Phones retain the old scene until all targets are ready.

Scene

Manual Slot Assignment

Codes appear below the matrix. Existing codes can update a position.

Atomic Configuration

Edit layouts, groups, schedules and artwork parameters together. Stale edits are rejected. Rollback creates a new revision.

Experimental PixiJS

Trusted artwork code only. Hosted on this Mac, without CDN access. Upload a version, then select the web renderer and preview it on the target phones.

Installation Reset

Erase pairings, wall settings, queued messages and downloaded media, then restart the controller. Connected phones will also clear unused media. You will need to pair the wall again.

The Matrix

Live text previews, connection state and app version. Click a phone for details.
