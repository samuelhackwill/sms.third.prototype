# Staff quick guide

Use this guide after an installer has paired and tested all screens.

To assign positions (app 2.1+): open **Pair / Position** and press **Start Pairing Mode**. Connected phones turn red. Tap each phone once, starting at the top left, moving left-to-right across each row, then down. Wait for green confirmation before tapping the next phone. Press **Stop Pairing** on the Mac whenever finished, even with fewer than 30 phones. Assignments are saved immediately; a full wall stops automatically. Starting another session begins again at slot 0 and replaces positions as you tap, without erasing untouched slots. Pairing expires after ten minutes for safety.

The dashboard opens on **Control**: Pair / Position first, **Send Test Text** second. Stop pairing, then press Send Test Text for red serif letters on black, once across each occupied row, right-to-left, with 750 ms between row starts. The actual text/emoji glyph bounds are measured and fitted to 97% of the shortest phone's height in that row, avoiding clipping and preserving a common row baseline. Emoji retain their normal system colors. This style uses the existing cached web-artwork renderer so it can change through GitHub without another IPA; WebKit paces its frames, independently of the native display-link target. It resumes exhibition mode and reports preparation/failure; offline paired phones are skipped and counted rather than blocking the test. The previous artwork remains in Advanced releases for reuse/rollback. All previous tools, including Night Mode, the virtual matrix, manual slot fields and scene editor, are preserved in **Advanced**.

**The Matrix**, the compact sticky column beside Control and Advanced, shows the controller's expected output per assigned phone, with state refreshed every three seconds. Test text draws directly in the matrix canvas using the phone renderer’s text-fitting calculations, layout and start time; selection and the web-preview checkbox are unnecessary. Tiles show battery percentage, plugged/unplugged status and thermal category (Heat OK, Warm, Hot or Critical). Additional badges flag low battery, app errors, background state, stale/offline readings or display callbacks below 75% of the reported target. Offline power readings are marked Last report. Click a tile to open persistent diagnostics, including whether the text test is waiting, displaying or finished. Plugged includes both charging and fully charged phones. Thermal categories are not temperature measurements, and callback rate is not a CPU measurement. Clicking only inspects a phone; use Select for Advanced actions in its details, then Advanced → Target: Selected phones, to target commands. On smaller screens the matrix stacks below the controls. Opening the dashboard joins the current point in the animation; it does not replay the one-pass text. Pairing colors, Identify, Night Mode and Blackout are also represented. Empty slots have no assigned output. Each card separates expected artwork from the phone's reported scene/status; an offline phone may differ from the controller preview. Other web artwork requires selecting phones and enabling web previews (up to four); image/video previews remain placeholders. Local draft previews are explicitly labeled; **Show Live Wall** returns to controller state.

Use the **Text speed** slider (20–1000 logical pixels/second) before sending a test. Try 80–120 for slower movement; the original speed was 240. It changes the next test, not the text already moving. The last sent speed is saved on the controller and restored when reopening the dashboard. The **Test message** field accepts text and emoji, including skin tones, joined sequences and flags; message and speed are saved together. No phone update is required for these controls. Only emoji provided by the phone's installed iOS can be guaranteed; newer unsupported glyphs may show missing-character boxes.

Native app **2.2 (build 5)** requests **60 frames/second**; older 2.1 apps requested 30. Install this IPA once for the smoother native renderer; GitHub server updates cannot change native code. **Advanced** phone cards show sampled display-callback rate and target after a heartbeat. This is a useful slowdown diagnostic, not proof every frame reached the screen. Actual sustained performance, thermals and battery behavior must be checked on the iPhone 6s. Speed and frame rate are independent. The browser's 30-screen preview remains approximate and capped around 30 fps; video and experimental WebView frame rates depend on their own playback/render loop.

For a published server update, open **Update Phone Wall** in Applications and approve once; no package reinstall or Terminal is required after installing version 2.2.0. Only committed/pushed source is downloaded. Update outside exhibition hours with internet available; normal operation remains offline-capable. Artwork-only changes do not require an IPA update.

Artistic editing and staged release instructions are in [RUNTIME.md](RUNTIME.md). Use one phone, then a selected group, then promote the same immutable release to the entire matrix. Do not treat a release as successful until its target phones report displayed; a preparation error leaves the previous artwork in place.

1. Switch on the dedicated router, screen chargers and Mac mini. If the Mac was deliberately shut down, press its power button and log into the installation account as instructed. Restored power alone may not start it.
2. Open **Phone Wall Dashboard** in Applications on the Mac mini. It signs in automatically; no Terminal or operator key is needed with the packaged installation. Check the device count and text status labels.
3. For the approved exhibition artwork, open **Advanced** and press **Start Exhibition**. Check all screens. If a scene needs selecting, choose the approved scene before starting.
4. At closing, open **Advanced** and press **Night Mode**. Screens become black and dim; phones remain plugged in and reachable. Do not shut them down individually.
5. Set Target to **Entire matrix** and use **Blackout** for an immediate black display. Use **Start Exhibition** to resume. Manual mode controls disable an enabled daily schedule; the installer must save the schedule again to reactivate it.
6. For a missing screen, find its Offline card. Click a neighboring paired screen, choose **Select for Advanced actions** in its details (repeat for other phones), set Target to **Selected phones**, then press **Identify**. The test pattern lasts 15 seconds. Check the missing phone's cable, charger and Wi-Fi. Ask the installer for USB recovery if it does not return. Return Target to **Entire matrix** afterward.

After an outage, restore router, chargers and Mac power and wait for reconnect. The packaged controller starts at boot, before login; logging in is only needed to open the dashboard. A fully powered-off iPhone cannot be switched on remotely by this app; use its physical power button if needed. Single App Mode reboot/autolaunch must have been verified for the deployed build.

Keep ventilation clear and cables secured. Remove any phone with a swollen battery, abnormal heat or unstable charging from service. Do not use personal accounts or store personal information on installation phones. The dedicated router travels with the wall when moving rooms.
